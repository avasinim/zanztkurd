## 1. Current public route confirmed

Yaron Matras's project page identifies the Kratylos repository as the post-August-2022 access route for the Database of Kurdish Dialects. The current database landing page is:

https://www.kratylos.org/~raphael/kurdish/database/

The legacy database index remains available at:

https://www.kratylos.org/~raphael/kurdish/database-of-kurdish-dialects/index.html

The indexed database documentation specifies five searchable dimensions:
- sample code;
- location;
- structural/grammatical tag;
- English questionnaire phrase;
- Kurdish text or text fragments.

It also explains that multiple criteria can be combined and that results can be downloaded as a table/spreadsheet or mapped.

The sample index explicitly lists K-078 as Şemdinli under Turkey (Kurmanji).

## 3. FoLD is a separate possible access route

The Aston University Forensic Linguistic Databank (FoLD) is a controlled-access repository that also signposts externally held datasets. Its public home page says data requests can take up to 14 days for review. A FoLD methods paper explains that some controlled datasets require detailed applications to FoLD and the data owner and may require secure access rather than direct download.

Therefore:
- Kratylos is the primary next route for the public Kurdish dialect database.
- FoLD is a secondary route if the relevant dataset is catalogued there or if Kratylos records require a separate access pathway.
- Do not assume FoLD access is automatically granted or that the K-078 records are themselves controlled.

FoLD:
https://fold.aston.ac.uk/
