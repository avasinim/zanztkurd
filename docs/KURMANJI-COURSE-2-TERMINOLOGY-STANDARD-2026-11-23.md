# کۆرسی ٢ — ستانداردی زاراوەکانی مۆرفۆلۆژی

**بەروار:** 2026-11-23  
**دۆخ:** ستانداردی کاریی پەسەندکراو بۆ ناوەڕۆکی ئەم کۆرسە  
**مەودا:** ١٢ وانەی کورمانجیی ستاندارد؛ وشەنامەی فێرکاری و نووسینی یەکگرتوو.

ئەم بەڵگەنامەیە مرجەعی یەکگرتووی زاراوەکانە. لە وانەکاندا یەکەم جار زاراوەی کوردی بەکاربهێنە و لە یەکەم بەکارهێناندا هاوتای ئینگلیزی لە کەوانەدا زیاد بکە؛ پاشان زاراوەی کوردی بەردەوام بەکاربهێنە. فۆڕمە لاتینییەکانی کورمانجی بە هیچ شێوەیەک بۆ گونجاندن لەگەڵ زاراوەی کوردی مەگۆڕە.

## ١. وشەنامەی بنەڕەتی

| English | زاراوەی ستانداردی کوردی | پێناسەی فێرکاری |
|---|---|---|
| root | **ڕەگ** | بەشی ناوەندیی وشە کە بنەمای واتایی وشەکە هەڵدەگرێت؛ لە شیکردنەوەدا لە مۆرفیمە زیادکراوەکان جیا دەکرێتەوە. |
| base | **بنەڕەت** | ئەو فۆڕمەیە کە مۆرفیمێک یان پاشگر/پێشگرێک پێوە دەبەسترێت؛ دەتوانێت لە ڕەگ فراوانتر بێت. |
| stem | **بنەی وشە** | ئەو فۆڕمەی وشەیە کە نیشانەی شێوەگۆڕیی ڕێزمانی وەردەگرێت؛ لە پێکهاتەی ئاڵۆزدا دەتوانێت ڕەگ و مۆرفیمی وشەسازی لەخۆ بگرێت. |
| morpheme | **مۆرفیم** | بچووکترین یەکەی فۆڕم و واتا/کاری ڕێزمانی؛ دەتوانێت سەربەخۆ یان بەستراو بێت. |
| inflection | **شێوەگۆڕیی ڕێزمانی** | گۆڕینی فۆڕمی وشە بۆ دەربڕینی زانیاریی ڕێزمانی وەک ژمارە، ڕەگەز، حاڵەت، کەس یان کات، بەبێ دروستکردنی وشەیەکی نوێ. |
| derivation | **وشەسازی (داڕشتن)** | دروستکردنی وشەی نوێ بە زیادکردنی مۆرفیمی وشەسازی؛ دەتوانێت واتا یان جۆری وشە بگۆڕێت. |
| syncretism | **یەکفۆڕمیی ڕێزمانی** | کاتێک دوو یان زیاتر خانە/کارکردی ڕێزمانی بە هەمان فۆڕمی دەرکەوتوو دەردەکەون؛ یەکسانیی فۆڕم بە مانای یەکسانیی کارکرد نییە. |
| grammatical gender | **ڕەگەزی ڕێزمانی** | پۆلێنکردنی ڕێزمانیی ناوەکان و ڕێککەوتنی پێوەندیدار؛ هەمیشە هاوتای ڕەگەزی سروشتی نییە. |
| number | **ژمارەی ڕێزمانی** | دابەشکردنی فۆڕمی ڕێزمانی بۆ تاک، کۆ و ئەگەر هەبوو ژمارەی تر. |
| transitivity | **تێپەڕیی کردار** | تایبەتمەندیی کردار لە پەیوەندی بە بەرکارەوە؛ کردارە تێپەڕەکان بەرکاری ڕاستەوخۆیان هەیە، کردارە ناتێپەڕەکان بەو شێوەیە بەرکاری ڕاستەوخۆیان نییە. |
| intransitivity | **ناتێپەڕیی کردار** | جۆری کردارێک کە بەرکاری ڕاستەوخۆی ڕێزمانی وەک کردارە تێپەڕەکان ناگرێت. |
| tense | **کاتی ڕێزمانی** | نیشاندانی پەیوەندیی ڕووداو بە کاتی قسەکردن، وەک ئێستا، ڕابردوو و داهاتوو. |
| aspect | **ڕوانگەی کردار** | شێوازی پیشاندانی ڕووداو لە ڕووی تەواوبوون، بەردەوامی یان دۆخی ناوخۆییەوە؛ لە کاتی ڕێزمانی جیاوازە. |
| imperfective | **ناتەواو** | ڕوانگەیەک کە ڕووداو وەک تەواونەبوو، بەردەوام یان دووبارەبووەوە پیشان دەدات؛ واتایەکی یەکسان بە «کاتی ئێستا» نییە. |
| case | **حاڵەتی ڕێزمانی** | نیشانە/فۆڕمی ناو یان جێناو کە پەیوەندیی ڕێزمانیی لە ڕستەدا دیاری دەکات. |
| direct case | **حاڵەتی ڕاستەوخۆ** | ناوی حاڵەتی ڕێزمانیی direct لە کورمانجی؛ لەگەڵ واتای ئاسایی «ڕاستەوخۆ» تێکەڵ نەکرێت. |
| oblique case | **حاڵەتی ناڕاستەوخۆ** | ناوی حاڵەتی ڕێزمانیی oblique لە کورمانجی؛ بە یەک ڕۆڵی واتایی سنووردار ناکرێت. |
| ergative alignment | **هاوتەریبەندیی ئەرگاتیڤ** | شێوازی ڕێکخستنی بکەر و بەرکار کە لە هەندێک پێکهاتەدا بکەری کردارە تێپەڕەکان بە فۆڕمی ناڕاستەوخۆ و بەرکار بە فۆڕمی ڕاستەوخۆ دەردەکەون؛ دەبێت بە کات و پێکهاتەی ڕستەوە دیاری بکرێت. |
| ezafe | **ئەزافە (ezafe)** | پەیوەندیی ڕێزمانیی نێوان ناو و هاوپەیوەندەکانی، وەک هاوەڵناو یان خاوەندار؛ فۆڕمەکەی بە پێی ڕەگەز، ژمارە و حاڵەت دەگۆڕێت. |

## ٢. جیاوازییە گرنگەکان

1. **ڕەگ ≠ بنەڕەت ≠ بنەی وشە:** ڕەگ بنەمای وشەیە؛ بنەڕەت ئەو فۆڕمەیە کە مۆرفیم پێوە دەبەسترێت؛ بنەی وشە ئەو فۆڕمەیە کە شێوەگۆڕیی ڕێزمانی وەردەگرێت. ئەم سێ زاراوەیە بە یەکتر مەگۆڕەوە.
2. **وشەسازی ≠ شێوەگۆڕیی ڕێزمانی:** یەکەم وشەی نوێ دروست دەکات؛ دووەم فۆڕمی ڕێزمانیی هەمان وشە دەگۆڕێت.
3. **کات ≠ ڕوانگەی کردار:** کات پەیوەندیی ڕووداو بە کاتی قسەکردنە؛ ڕوانگەی کردار شێوازی بینینی ڕووداوە.
4. **ڕەگەزی ڕێزمانی ≠ ڕەگەزی سروشتی:** ڕەگەزی ڕێزمانی تایبەتمەندیی پۆلێنکردنی زمانە.
5. **یەکفۆڕمیی ڕێزمانی ≠ هاوواتایی:** دوو کارکرد دەتوانن فۆڕمیان یەکسان بێت، بەڵام واتا و کارکردیان جیاواز بێت.
6. **هاوتەریبەندیی ئەرگاتیڤ ≠ ڕیزبەندیی وشەکان:** یەکەم پەیوەندیی حاڵەت و ڕێککەوتنی ڕێزمانییە؛ دووەم شوێنی پێکهاتەکانە لە ڕستەدا.

## ٣. ستانداردی نووسین و بەکارهێنان

- نووسینی ستانداردی پەیوەندیی ezafe لە دەقی کوردیدا **«ئەزافە»** ـە؛ لە دەقی پێشوو «ئیزافە» بە هەمان زاراوە ئاماژەی پێکراوە و لە Seed ـەکاندا یەکگرتوو کراوەتەوە.
- لە یەکەم بەکارهێناندا: «ڕوانگەی کردار (aspect)»، «ناتەواو (imperfective)»، «هاوتەریبەندیی ئەرگاتیڤ (ergative alignment)».
- لە ناو نموونە کورمانجییەکاندا هیچ پیت، نیشانە، فاصلە یان فۆڕمێک مەگۆڕە؛ تەنها ڕوونکردنەوەی کوردی دەکرێت.
- زاراوەی «حاڵەتی ڕاستەوخۆ/ناڕاستەوخۆ» تەنها وەک ناوی حاڵەتی ڕێزمانی بەکاربهێنە، نەک وەک واتای ئاساییی شوێن یان ئاراستە.

## ٤. ئەنجامی پشکنینی Seed

پێنج بەشی Seed پشکنران. پێش یەکگرتنەوە، نووسینی «ئیزافە» ٢٩ جار و «ئەزافە» ٣٠ جار هەبوو. لە هەموو پێنج بەشەکەدا نووسینی «ئیزافە» بۆ نووسینی ستانداردی «ئەزافە» یەکگرتوو کرا. هیچ فۆڕمێکی لاتینیی کورمانجی نەگۆڕدرا.

پشکنینی داتابەیس پێش گۆڕانکاری نیشانی دا کە لە هەردوو داتابەیسی تاقیکردنەوە و بەرهەمهێناندا هیچ بەکارهێنانێکی «ئیزافە» لە ١٢ وانەکەدا نەماوە؛ بۆیە Migration ـێکی بێ‌پێویست بۆ داتابەیس زیاد نەکرا.

## ٥. سنووری ئەم ستانداردە

ئەم وشەنامەیە بڕیاری زاراوەکان یەکلا دەکاتەوە، بەڵام بە تەنها واتای ئەوە نییە کە هەموو وانەکان لە ڕووی نموونە، پارادایم، وەڵامی نموونەیی و پێشکەوتنی فێرخوازەوە ئامادەن. ئەو پشکنینانە لە چێکلیستی جیاوازدا بەردەوام دەبن.
