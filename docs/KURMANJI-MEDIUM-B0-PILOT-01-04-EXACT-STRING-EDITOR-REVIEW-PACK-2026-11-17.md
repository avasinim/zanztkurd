## 1. Purpose and review protocol

This pack turns the open editorial gates into a line-by-line review instrument. It is intended for a proficient Kurmanji editor familiar with the proposed Hawar-based written standard and, for phonological claims, a Kurmanji linguist.

**Important:** all entries in the “Current string / item” column are the existing draft wording or exercise items, not proposed corrections. Reviewer notes are questions, not assertions that a string is wrong. Preserve the exact source wording until the reviewer records a decision.

For each ID, the reviewer should record:
- **Decision:** approve / revise / reject / defer.
- **Approved form:** exact final Kurmanji wording (leave blank until decided).
- **Variety/register:** standard written form, regional form (name it), colloquial/register note, or not applicable.
- **Reason/source:** concise linguistic reason and page-level source if a factual claim is involved.
- **Reviewer/date:** role and date; personal details need not be published.
- **B0 test:** independently understood / understood with modelling / not understood.

Do not use Sorani or English translations as hidden learner-facing scaffolding in Pathway B. Internal editorial notes may use English. Do not replace a difficult Kurmanji instruction with an English/Sorani gloss in the learner payload; simplify and model it in Kurmanji.

## 6. Specialist evidence notes for the reviewer

1. Haig (2018), “Northern Kurdish (Kurmanjî),” §2.1.1, pp. 109–112, describes the eight-vowel analysis and the written forms: full/tense vowels /a, i, e, u, o/ written `a, î, ê, û, o`; lax vowels /æ, ʊ, ɪ/ written `e, u, i`. It also discusses a central vowel /ɨ/ written `i` in some lexical items. This makes the lesson's distinction between written grapheme recognition and sound classification essential. See the chapter PDF and the examples around printed pp. 110–112: https://multicast.aspra.uni-bamberg.de/data/pubs/Haig2018_Northern-Kurdish_Kurmanji.pdf
2. Haig & Öpengin (2018), “Kurmanjî Kurdish in Turkey: Structure, varieties, and status,” §3.1.1, gives the basic eight simple vowel phonemes and the corresponding standard spellings, while also discussing the central vowel and regional variation: https://www.uni-bamberg.de/fileadmin/aspra/06_Team/Publications_and_CV/HaigOepengin2018_Kurmanji_Kurdish_.pdf
3. Haig (2018) explicitly describes Standard Kurmanjî as a written standard based loosely on Cizre/Botan and using a modified Roman alphabet whose norms derive from Hawar conventions. This supports a written-standard reference, not a claim that every spoken variety is identical: https://multicast.aspra.uni-bamberg.de/data/pubs/Haig2018_Northern-Kurdish_Kurmanji.pdf

These sources support general linguistic claims; they do not certify the instructor-created dialogue, classroom commands, task wording or every lexical example. Each such item still requires editor review.

## 8. Release gate

No lesson is approved merely because this review pack exists. Release requires:
- written reference variety and alphabet policy approved by the project owner;
- all P0 phrase/concept issues resolved by a proficient Kurmanji editor;
- specialist review of vowel/phonological statements;
- answer keys complete and internally consistent;
- B0 learner comprehension observed with Kurmanji-only instruction;
- explicit owner approval before any learner-facing draft, seed SQL, application record or release branch is changed.

**Protected scope:** this pack adds review IDs and records questions only. It does not change any existing lesson, seed, code, database, migration, CI, PR or deployment.
