# Course 2 — Lesson 12: Final Review and Assessment Design Proposal
Date: 2026-11-23
Status: Documentation-only proposal; no lesson-content changes authorized or performed.

## 1. Current state
The stored Lesson 12 payload is titled **پێداچوونەوە و تاقیکردنەوەی کۆتایی**. It reviews:
- morphology, morphemes, roots, prefixes/suffixes and indefinite `-ek`;
- nouns, gender/number, ezafe, adjectives and possession;
- pronouns, direct/oblique case, tense, transitivity, negation, questions and word order;
- a final learner task asking for grammatical analysis of a chosen Kurmanji sentence, with source/context support.

The lesson has reflective questions and a source-discipline reminder. However, the current payload does not provide a scored test, item-by-item points, time guidance, a marking rubric, or an answer key. The practical task has no controlled source passage, length or minimum target structures.

## 2. Main finding
At present, Lesson 12 is a **guided review and open analysis task**, not a fully specified formal final examination. The word “تاقیکردنەوە” in the title may lead learners to expect a scored assessment that the lesson does not yet contain.

Keep the source-discipline note: learners must support grammatical claims with evidence and context, and new examples must not be invented.

## 3. Two viable editorial paths

### Option A — Keep Lesson 12 as a review lesson (conservative default)
- Rename the title only after approval to **پێداچوونەوەی کۆتایی**.
- Keep the broad review structure and final analysis activity.
- Add a short lesson-to-course checklist showing which earlier lesson each topic revisits.
- Supply one worked analysis using an already source-verified course example, not a newly invented sentence.
- Turn the existing review questions into a small set of applied prompts with model answers or marking criteria.
- Do not imply that a pass/fail exam is taking place.

This path is the lowest-risk option while terminology, source gaps and worked examples in Lessons 1–11 remain unresolved.

### Option B — Make Lesson 12 a formal final assessment
If the course owner wants an actual exam, design it as a separate, explicit assessment section after the review. Before writing test items, approve:
- assessment purpose: diagnostic, formative, or summative;
- duration and delivery conditions;
- total points and weighting by learning outcome;
- pass threshold or grading bands;
- permitted references and whether source citation is assessed;
- accepted dialect/orthographic variants;
- accommodations and retake policy, if applicable;
- answer key and marking rubric.

Do not select a pass threshold or exam duration by guesswork. They are course-owner decisions, and item difficulty must be calibrated against what the 12 lessons actually teach.

## 4. Proposed assessment blueprint (for approval, not an exam paper)
If Option B is selected, use a balanced set of item types rather than relying only on recall questions:

| Domain | Source lesson(s) | Suitable evidence of learning |
|---|---|---|
| Word and morpheme structure | 01–02 | Identify and segment a taught form; distinguish root from base using the approved terminology. |
| Noun, gender and number | 03 | Interpret a source-verified noun form and explain the relevant agreement. |
| Indefiniteness and ezafe | 04–05 | Compare fully contextualized examples; distinguish case marking from ezafe. |
| Possession and reflexive | 06 | Analyze a taught possessive construction and keep the `xwe` explanation within its verified scope. |
| Pronouns and case | 07 | Identify direct/oblique forms and explain the grammatical context without equating case mechanically with subject/object. |
| Verb and agreement | 08 | Compare the three taught clause types using complete, source-verified examples. |
| Tense and aspect | 09 | Contrast taught forms and explain the distinction without overgeneralizing prefixes. |
| Negation and questions | 10 | Analyze only source-verified negation/question material; exclude unresolved heading content until clarified. |
| Word order and clause structure | 11 | Parse a complete source-verified clause; distinguish SOVG from the separate ergative example. |
| Integrated analysis | 01–11 | Provide a structured analysis of a controlled, cited course passage, with evidence for each claim. |

No question should assess a grammatical distinction that has not been clearly taught and practiced in the preceding lessons. In particular, avoid making the unresolved Lesson 10 heading or unverified question forms examinable.

## 5. Suggested marking principles (not a point allocation)
A rubric should distinguish:
1. **Identification:** the learner identifies the relevant form or construction.
2. **Analysis:** segmentation and grammatical function are correctly explained.
3. **Context:** the learner uses the complete phrase/clause and does not infer function from a matching suffix alone.
4. **Evidence:** source-based claims cite the taught example or reference where required.
5. **Clarity:** the explanation uses the approved course terminology.

Accept only variants documented for the course's selected Standard Kurmanjî scope. Where the source records dialect variation, the answer key must state which variants are accepted and why. Do not penalize a learner for a variant that the course itself has not clearly excluded.

## 6. Prerequisites before a formal exam can be approved
- Resolve the shared terminology register, especially root/base/stem and tense/aspect.
- Complete the source and instructional corrections in Lessons 4–5 and 7–11.
- Resolve Lesson 10's ambiguous heading and verify question construction for the selected variety.
- Ensure each lesson has a worked example and applied practice before testing it.
- Select a controlled source passage and verify every form, gloss and translation.
- Prepare answer keys and accepted-variant notes, then independently review the test for coverage and ambiguity.

## 7. Recommendation
Adopt **Option A for the current course version**: treat Lesson 12 as a final review until the earlier lessons are fully revised and the owner explicitly approves a formal exam. If a formal exam is desired later, add it as a clearly labeled second part with approved duration, scoring, rubric and answer key. This avoids promising a test that the current lesson does not yet deliver.
