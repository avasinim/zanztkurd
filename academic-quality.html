چوارچێوەی ئەکادیمی

کوالیتی و بەڕێوەبردنی ناوەڕۆک

ئەم پەڕەیە ڕێکارەکانی پشکنین، پاراستنی سەرچاوە، versioning و تۆمارکردنی گۆڕانکارییەکان لە پرۆژەی زانستی کورد ڕون دەکاتەوە.

١. پشکنینی ناوەڕۆک

پشکنین دەبێت لە نێوان دەقی سەرچاوە، ناوەڕۆکی سایت، metadata و ڕێنووسی کۆدی ئاڤاشین جیاوازی بکرێت. دەقی کتێب و نموونەکانی سەرچاوە نابێت بە چاک‌کاریی گشتی بگۆڕدرێن، مەگەر گۆڕانکارییەکە بە ڕوونی پەسەند کرابێت.

٢. سەرچاوە و ڕەچەڵەک‌نامە

هەر ناوەڕۆکێک کە پشت بە سەرچاوەی دیاریکراو دەبەستێت، دەبێت جۆری سەرچاوەکە و پەیوەندییەکەی بە ناوەڕۆک ڕون بێت. سەرچاوە یارمەتیدەرەکان نابێت بە شێوەی خۆکار وەک سەرچاوەی سەرەکی پیشان بدرێن.

٣. versioning و تۆماری گۆڕانکاری

گۆڕانکارییە گرنگەکانی ساختار، ناوەڕۆک، ڕێنووس، SEO، security و deployment دەبێت لە CHANGELOG.md تۆمار بکرێن؛ بەروار، فایل یان بەش، جۆری گۆڕانکاری و Commit/SHA ـی پەیوەندیدار بنووسرێت.

٤. ناسنامەی نوسەر و پشکنەر

تەنیا ناوی ئەو کەسە یان دامەزراوەیەک دەبێت وەک نوسەر، پشکنەر یان پەسەندکەر پیشان بدرێت کە ناسنامە و ڕۆڵەکەی بە زانیاریی پشتڕاستکراوە پشتگیری کراوە. هیچ ناوی پشکنەری ئەکادیمی یان پەسەندکردنی فەرمی لە خۆمانەوە زیاد ناکرێت.

٥. دۆخی پشکنین

«پشکنراو» نابێت بە مانای «پەسەندکراوی زانکۆیی» یان «بڕوانامەدار» بێت. دۆخی هەر پەڕەیەک دەبێت لەسەر بنەمای ئەو کاری ڕاستەقینەیە دیاری بکرێت کە لە repository ـدا ئەنجام دراوە.

بنەمای شەفافیت: ئاڤاشین نابێت پشکنین، reviewer، accreditation یان پشتگیریی دامەزراوەیی دروست بکات بەبێ بەڵگەی ڕاستەقینە. ئەوەی لە repository ـدا تۆمار نەکراوە، نابێت وەک کاری تەواوکراو ناسێنرێت.
