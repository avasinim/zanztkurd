# سیستەمی وانەکان

ئەم بەشە ناوەڕۆکی وانەکان لە سیستەمێکی ڕێکخراودا هەڵدەگرێت.

## پێکهاتە

- `index.json` — کاتەلۆگی سەرەکیی وانەکان
- `section-XX/` — بەشەکانی کۆرس
- `lesson-XXX.json` — زانیاری و metadataی وانە
- `lesson-XXX.md` — ناوەڕۆکی خوێندنەوەی وانە

## چۆنیەتی زیادکردنی وانەی نوێ

١. فایلێکی `lesson-XXX.json` دروست بکە.
٢. فایلێکی هاوتای `lesson-XXX.md` دروست بکە.
٣. `path` و `contentPath` لە `lessons/index.json` تۆمار بکە.
٤. `lesson.html?id=LESSON_ID` بە شێوەی خۆکار وانەکە بار دەکات.
٥. ناوبەری وانەی پێشوو و داهاتوو لەسەر بنەمای `index.json` دروست دەبێت.

## پێشکەوتن

پێشکەوتنی فێرخواز لە `localStorage` هەڵدەگیرێت؛ بۆیە پێویستی بە backend نییە بۆ قۆناغی ئێستای پڕۆژە.

کاتێک سیستەمی هەژمار و backend زیاد کرا، ئەم بەشە دەتوانرێت بۆ تۆمارکردنی پێشکەوتنی هەر بەکارهێنەرێک بگوازرێتەوە.

## تێبینی

پەڕەی سەرەکی و پەڕەی چوونەژوورەوە لەم ساختارەدا دەستکاری ناکرێن. ناوەڕۆکی وانەکان بە جیاوازی لە UIی سەرەکی پەرەی پێدەدرێن.
