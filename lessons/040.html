وانەی ٣/٧ — دەوری فۆنێتیکی و مۆرفۆلۆجیی پیتی (ی)

١. فۆنی (ی) و سازبونی فۆنێتیکی

فۆنی (ی) فۆنێکی خلی و ژێدارە. لە کاتی سازبونیدا، نێوەڕاستی زمان بەرەو ڕەقەمەڵشو نزدیک دەبێتەوە و لەو نزیک‌بونەوەیەدا هەوا بە شێوەی بەندێکی کەم و خشۆک دەردەچێت و دەبێتە هۆی لەرینەوەی تاڵە دەنگیەکان.

٢. دەوری ڤاوڵی ئازادی (ی)

گرافیمی (ی) لە نێو وشەدا دەتوانێت بە شێوەی ڤاوڵی بەند دەرکەوێت؛ وەک لە سیر، شیر، میر، شادی، یاری، میوان. لە ئاستی فۆنێتیکی‌دا دەرکەوتنی درێژ و کێرشاوەیی ئەم ڤاوڵە لە بێژەدا هەست پێ دەکرێت، بەڵام لە نوسین‌دا بە یەک (ی) دەنوسرێت.

٣. پیتی (ی) و دو ڤاوڵی تەنیشت یەک

کاتێک دو ڤاوڵ لە پاڵ یەک دەکەون، پڕۆسەی فۆنۆلۆجی و فۆنێتیکی دەتوانێت ببێتە هۆی تێچون و تواندنەوەی یەکێک لە ڤاوڵەکان. کتێبەکە ئەم دیاردەیە بە نموونەکانی مامۆستا + ەکە = مامۆستاکە، سارا + ەکە = ساراکە، شانە + ەکە + ان = شانەکان، دارە + ەکە + ان = دارەکان و شادی + ین = شادین ڕون دەکاتەوە.

٤. (ی) و مۆرفیمە بەندەکان

لە بازنەی مۆرفۆلۆجیا‌دا (ی) دەتوانێت لەگەڵ مۆرفیمە بەندەکانی (ێتی) و (انە) پەیوەندی هەبێت و لە وشەداڕێژین‌دا چالاک بێت.

ناشیرینی → ناشیرینێتی → ناشیرینانە
منداڵی → منداڵێتی → منداڵانە
جوانی → جوانێتی → جوانانە
پیری → پیرێتی → پیرانە
درێژی → درێژێتی → درێژانە

٥. (ی) لە کۆتایی ڤاوڵی ئازاد

کاتێک ڕیشەی وشە بە ڤاوڵ کۆتایی دێت و (ی) بەدوایدا دێت، پڕۆسەی کۆنسۆنەنتی زیادبوو دەرکەوێت؛ یەکەم (ی) کۆنسۆنەنتی /y/ و دوەم (ی) ڤاوڵی /î/ دەبێت.

نامۆیی، مامۆستایی، بانەیی، شارەزایی

٦. ئاوێتەبون و یەکبون

لە تێکەڵ‌بونی ڤاوڵی /ی/ و /ە/ دەتوانێت ڤاوڵی [ێ] پەیدا ببێت:

شادی + ی + ەکە → شادییەکە → شادیێکە [ی، ێ]
کوردی + ی + ەکە → کوردییەکە → کوردیێکە [ی، ێ]
یاری + ی + ەکە → یارییەکە → یاریێکە [ی، ێ]

٧. دەوری مۆرفۆلۆجیی (ی)

(ی) لە بازنەی مۆرفۆلۆجیا‌دا دەتوانێت ئەرکی گیرەکی وشەداڕێژ هەبێت و لە ئاڵوگۆڕی ئاڵقەی وشەدا ڕۆڵ بگێڕێت؛ وەک:

باش → باشی، خراپ → خراپی، ناسک → ناسکی، بەخت → بەختی، مەست → مەستی، غەم → غەمی، شاد → شادی.

پوختەی وانە

لە ئەم وانەیەدا دەوری (ی) لە دو ئاستی سەرەکی‌دا خرایە ڕوو: فۆنێتیک و مۆرفۆلۆجی. لە فۆنێتیک‌دا تایبەتمەندی سازبونی فۆنی (ی) و دەرکەوتنی ڤاوڵی بەستراو و کێرشاوەیی گرنگە؛ لە مۆرفۆلۆجی‌داش (ی) لە پەیوەندی بە مۆرفیمە بەندەکان، وشەداڕێژین و پڕۆسەکانی ئاوێتەبون و یەکبون‌دا دەردەکەوێت.
