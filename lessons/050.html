سەگمێنت و مۆرفۆفۆنێمی (ی)

سەگمێنت و مۆرفۆفۆنێمی /ی/ دەورێکی چالاک و بەهێزی لە نێو زوانی کوردیک لە سەر ئاستی سینتەکس و بازنەی مۆرفۆلۆجی هەیە. ئەم مۆرفۆفۆنێمە لە ئاستەکانی سینتەکسی، مۆرفۆلۆجی، فۆنۆلۆجی، فۆنێتکی و لێکسیمی دەردەکەوێت.

١. لە بازنەی فۆنێتیکی

گرافیمی /ی/ لە ئاستی فۆنی نیمەبزوێن، کۆنسۆنەنت و ڤاوڵ دەردەکەوێت. فۆنی /ی/ فۆنێکی خلی و ژێ‌داری خشۆکی ڕەقەمەڵاشوییە. نێوەڕاستی زمان لە نزیک‌ترین بەشی ڕەقەمەڵاشو نزیک دەبێتەوە و هەوا بە شێوەیەکی بەند و خشۆک دەردەچێت.

٢. دەوری ڤاوڵی ئازادی (ی) لە فۆنۆلۆجی

لە وشەکانی وەکو «سیر، شیر، میر، شادی، یاری، میوان»، گرافیمی /ی/ بە شێوەی ڤاوڵ دەردەکەوێت. لە دۆخی بەکارهێنانی مەیدانی، فۆنەکە دەتوانێت بە شێوەی کێشراوە بیسترێت، بەڵام لە ڕێنوسدا بە یەک /ی/ دەنوسرێتەوە کاتێک ئەرکی واچ و فۆنێمی نیە.

ڕێسای دەرکەوتنی /ی/ لە دۆخێکدا چالاک دەبێت کە دو ڤاوڵ بکەونە پاڵ یەکتر و مۆرفیمی سەرخستنی نێوانی /ی/ لە بازنەی مۆرفۆلۆجی زوانی کوردیک دەردەکەوێت.

٣. دۆخە مۆرفۆلۆجیەکانی /ی/

دۆخی ناسراوکردن

ناو + سەرخستنی نێوانی ڤاوڵی لکێنەری (ی) + مۆرفیمی بەندی (ەکە):

چەقۆ + ی + ەکە = چەقۆیەکە
شانە + ی + ەکە = شانەیەکە
پەردە + ی + ەکە = پەردەیەکە

دۆخی کۆکردن

ناو + نێوانجی /ی/ + مۆرفیمی کۆی (ان):

مامۆستا + ی + ان = مامۆستایان
فێرگە + ی + ان = فێرگەیان
برا + ی + ان = برایان
شارەزا + ی + ان = شارەزایان
زانا + ی + ان = زانایان

دۆخی کۆکردنی ناو بە پەیدابونی جێناوی /ی/

مامۆستا + یان = مامۆستایان
فێرگە + یان = فێرگەیان
برا + یان = برایان
شارەزا + یان = شارەزایان
زانا + یان = زانایان

دەنگی گەیەنەر و لێکسیکۆلۆجیا

بە خۆشی + ی + ەوە = بە خۆشیەوە
بە جوانی + ی + ەوە = بە جوانیەوە
ئێوارێ + ی + ەوە = ئێوارێیەوە

تێ‌چون و تواندنەوە

کاتێک دو ڤاوڵ لە پاڵ یەکتر دەکەون و ڤاوڵەکان لە دۆخی بەرز و نزم دان، لە پڕۆسەی فۆنۆلۆجی و فۆنێتیکی، ڤاوڵی نزم دەتوانێت تێ‌بچێت و بتوێتەوە. لە سەرچاوەدا ئەم ڕەوتە بە نمونەی /ە/ و /ی/ و هەروەها /و/ و /و/ و /ا/ باس کراوە.

٤. دەوری /ی/ لە مۆرفۆلۆجیا

پیتی /ی/ لە بازنەی مۆرفۆلۆجیکاڵدا ئەرکی گیرەکی وشەداڕێژی هەیە و لە داڕشتنی ناو و ئاوەڵناو بەکار دێت.

باش + ی = باشی
خراپ + ی = خراپی
سور + ی = سوری
ناسک + ی = ناسکی
بەخت + ی = بەختی
مەست + ی = مەستی
غەم + ی = غەمی
شاد + ی = شادی

ئیزافەی پێکهێنان

دم + ی + فش = دمی فش
زوڵف + ی + خاو = زوڵفی خاو
سەر + ی + پان = سەری پان
لیچ + ی + شۆڕ = لیچی شۆڕ
ژن + ی + چاک = ژنی چاک
چاو + ی + کاڵ = چاوی کاڵ
دڵ + ی + ناسک = دڵی ناسک

ناوی واتایی

کز + ی = کزی
باریک + ی = باریکی
پان + ی = پانی
پیس + ی = پیسی
خاوێن + ی = خاوێنی
پاک + ی = پاکی

بچوک‌کردنەوە

پشیلە → پشی
نازدار → نازی
دڵنیا → دڵی
گوڵ‌زار → گوڵی
سۆزان → سۆزی

ئاوەڵ‌کردار

ژێر + ی = ژێری
خوار + ی = خواری
بڵیند + ی = بڵیندی
تەنیشت + ی = تەنیشتی
بەرز + ی = بەرزی

گرێدان و نیسبیەت

کورد + ی = کوردی
گوند + ی = گوندی
کێو + ی = کێوی
شار + ی = شاری
نیشتمان + ی = نیشتمانی
بازاڕ + ی = بازاڕی

٥. دەوری /ی/ لە سینتەکس

لە بازنەی سینتەکس، /ی/ لە پێکهاتەی فرێز و گرێی ناوی و لە پەیوەندی نێوان ناو و ئاوەڵناو دەردەکەوێت.

گوڵ + ی + جوان = گوڵی جوان
ڕەنگ + ی + سور = ڕەنگی سور
مرۆڤ + ی + زانا = مرۆڤی زانا
کتێب + ی + باش = کتێبی باش
گیاندار + ی + جوان = گیانداری جوان

ئیزافە و خاوەندارێتی

دڵی من ← دڵ ئی من
دڵی تۆ ← دڵ ئی تۆ
دڵی ئەو ← دڵ ئی ئەو
دڵی ئێمە ← دڵ ئی ئێمە
دڵی ئێوە ← دڵ ئی ئێوە
دڵی ئەوان ← دڵ ئی ئەوان

پێکهاتەی ئیزافە

کتێب + ی + سابیر = کتێبی سابیر
پێنوس + ی + مامۆستا = پێنوسی مامۆستا
دەفتەر + ی + ئاڤاشین = دەفتەری ئاڤاشین
زانست + ی + ڤێرسین = زانستی ڤێرسین
باغ + ی + هاوسێ = باغی هاوسێ

٦. جۆرەکانی دەرکەوتنی /ی/ لە گرێی ناوی

لە سەرچاوەدا دۆخە جیاوازەکانی خستنەپاڵ، دانەپاڵ، ئیزافە، جێناو و گرێی ناوی بە نمونە ڕون کراون. لەوانە:

منداڵی من
یادگاری جوان
سەربەرزی یار
سپی بەفر
یادگاری یار
نەوی شاخ
سەربەرزی نیشتمان

٧. هێز و ئاوازە

لە دۆخی دەرکەوتنی /ی/، هێز و تەوژمیش دەورێکی گرنگ دەبینن. شوێنی هێز دەتوانێت شێوەی بێژە و بیستنی فۆنەکە بگۆڕێت، بە تایبەت لە کۆتایی بڕگە و لە پەیوەندی نێوان ڤاوڵ و کۆنسۆنەنت.

ش + ی + ر = شیر
پ + ی + ر = پیر
ق + ی + ر = قیر
ج + ی + ر = جیر
م + ی + ر = میر
س + ی + ر = سیر
ت + ی + ر = تیر
گ + ی + ر = گیر

٨. جیاوازی دۆخی ڤاوڵ و کۆنسۆنەنت

لە دۆخی /ی/ی ڤاوڵی و کۆنسۆنەنتی، هەر دو کۆدێکی فۆنێتیکی جیاوازن، بەڵام گرافیمی پیتەکە یەکە. لە دۆخی کۆنسۆنەنتی، کۆتا شوێنی بڕگە بەندترە و ڕێگەی کێشانەوەی ڤاوڵی نیە.

گ + ی + ا = گیا
چ + ی + ا = چیا
ج + ی + ا = جیا
گ + ی + ا + ن = گیان
ژ + ی + ا + ن = ژیان
ن + ی + ا + ن = نیان

٩. کەرستەکەرتی و دەرکەوتنی /ی/

لە سەرچاوەدا پەیوەندی دۆخی /ی/ بە کەرستەکەرتی، هێز، ئاوازە، بڕگە و بەستێنی ڕستە باس کراوە. هەروەها نمونەی «وشەناسی زمانی کوردی» و جۆرە جیاوازەکانی دەرکەوتنی /ی/ لە گرێی ناوی هێنراوە.

کۆتایی بەشەکە

سەرچاوەکە جۆرە جیاوازەکانی دەرکەوتنی /ی/ لە ئاستەکانی فۆنێتیک، فۆنۆلۆجی، مۆرفۆلۆجی و سینتەکس پێکەوە دەخاتەڕو و لەسەر ڕێنوس، کەمکۆشینی زوان و دۆخی سروشتی و ژینگەیی زوانی کوردیک گفتوگۆ دەکات.
