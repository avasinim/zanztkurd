ڤاوڵی بەندبو و /و/ی خلی

بەندبونی ڤاوڵ، سرتێس، /شوا/ و دەوری /و/ لە پڕۆسەی فۆنێتیکی و سینتەکسی

سەرچاوەی وانە: سابیر ژاکاو · فۆنێتیک و فۆنۆلۆجی کوردیک · لاپەڕەکانی ٥٣٠–٥٣٦

١. ڤاوڵی ئازاد و ڤاوڵی بەندبو

لە کاتی کێشانەوەی ڤاوڵ، ئەگەر پاش و پێشی ڤاوڵەکە ئازاد بێت، ڤاوڵەکە بە شێوەیەکی ئازاد و ڕەها دەکێشرێتەوە. بەڵام ئەگەر کۆنسۆنەنتێک لە پاشی پەیدا بو، ڤاوڵەکە بەند دەکرێت و پێش ئازاد سووڕانەوەی دەگیرێت.

نمونەکانی کتێب: پیر، میر، سیر، کر، سور، دور. لەم وشانەدا ڤاوڵەکە لە نێوان کۆنسۆنەنتەکان‌دا بەند دەبێت و سروشتی کێشاوەی خاو دەداتەدەست.

٢. ڤاوڵی /و/ لە کۆتایی بڕگە

کاتێک /و/ لە کۆتایی بڕگە بێت، سروشت و هێزێکی کێشاوەیی هەیە. ئەگەر کۆنسۆنەنتێک لە پاش ڤاوڵەکە دەربکەوێت، سروشتی کێشاوەیی و سرتێسەکەی لەدەست دەدات و ڤاوڵەکە بێ‌هێز دەبێت.

نمونە: دو + → دور، سو + → سور، سی + → سیر؛ هەروەها بار + ی → باریک، زانا + → زانام، زانای، زاناو، زاناش، زانات، چەقۆ + → چەقۆش، شانە → شانەش، سنە → سنەم، زیندو + → زیندوم، مردو + → مردوم، سپی + → سپیش، نەوی + → نەوت، یادگاری + → یادگارت.

٣. سرتێس و دۆخی ڤاوڵ و کۆنسۆنەنت

لە دۆخی سرتێس‌دا جوداکردنەوەی «ڤاوڵ» و «کۆنسۆنەنت» بە هێزی سرتێس و خواستی بەکارهێنەرەوە پەیوەندی هەیە. کتێب لە نموونەکانی «کردووە، مێژووە، خانووە» و شێوەکانی «کردوووە، مێژوووە، خانوووە» دەڕوانێتەوە.

٤. /شوا/ و ڕێنوس

لە بازنەی دەرکەوتنی [و]، کورتە ڤاوڵ و نیمچە ڤاوڵی /شوا/ دەرکەوتنێکی تایبەتی هەیە. لە ڕێنوسی ڕاست‌چین گرافیم و هێمای تایبەتی نیە و وەک فۆن و واچێکی چاڵاک لە زوانی کوردیک‌دا دەردەکەوێت.

لە پەیکەرە مێژوویی و بازنەی ئێتیمۆلۆجی‌دا، نیمچە ڤاوڵ و ڤاوڵی نزمی /شوا/ دەتوانێت بەرەو ڤاوڵی بەرزی [وو] بەرز بکرێتەوە و لە پڕۆسەی سازگە و بەرهەم‌هێنان‌دا دۆخی ڤاوڵی گرژ و کپ دروست بکات.

٥. /شوا/ لە نێوان دو کۆنسۆنەنت

لە زوانی کوردیک‌دا /شوا/ بە شێوەیەکی سروشتی و چاڵاک زۆرجار لە نێوان دو کۆنسۆنەنت پەیدا دەبێت و ئەرکی /و/ هێزێکی خلی وەردەگرێت:

و + شوا + ش + ە = وشە

و + شوا + ێ + ن + ە = وێنە

و + شوا + ر + ی + ا = وریا

ز + شوا + و + ە = زوە

ب + شوا + و + ە = بوە

٦. /و/ لە کۆتایی فۆنی بڕگە

لە دۆخی کۆتا فۆنی بڕگە، فۆنێمی خلی /و/ لە بازنەی ڤاوڵ‌دا دەتوانێت دو [وو]ی خۆی بپارێزێت:

تەزو + و + ە = تەزوە؛ مردو + و + ە = مردوە؛ خانو + و + ە = خانوە؛ هاتو + و + ە = هاتوە.

ئەم ڕێسا و قانونە فۆنێتیکیە ژینگەییەکان لە تێ‌چوون و بەرز و نزم‌کردنەوەی فۆنێتیكی‌دا بۆ ڕێنوسێکی سادە و جوان یارمەتیدەرن.

٧. درێژکردنەوەی ڤاوڵ

کتێب باس لە ڤاوڵی درێژکراو دەکات و ئەو پاساوەی کێشانەوەی ڤاوڵی [وو] بە پێی تێگەیشتنی فۆنێتیکی و فۆنۆلۆجی شی‌دەکاتەوە. لە هەمان کات‌دا، دۆخی ڤاوڵی بەندبو و [یی] لە وشەکانی شیر، پیر، میر، ڕیز هەمان هێز و کۆدی فۆنێتیکی لە میکانیزمی بەرهەم‌هێنانی ڤاوڵ نیشان دەدەن.

٨. سرتێس و مەودای دەنگ

لە وشەکانی دوکەڵ، بارەدو، نوسین، زەڵەکو، مو‌قڵێش و هەروەها داهاتو، ڕابردو، کەژو، سەرو، دۆخی سرتێس و مەودای دەنگ لە پێکهاتەی بڕگەدا نیشان دەدرێت.

٩. ئاوێتەسازی لە مۆرفۆلۆجی

لە پڕۆسەی مۆرفۆلۆجی‌دا یەکێک لە [و]ەکان دەتوانێت تێ بچێت:

شت + و + مەک ← شمەک

کۆڵ + و + بار ← کوڵبار

وت + و + وێژ ← وتوێژ

لە هەمان پڕۆسەدا دەرفەتی دەرکەوتنی جوتەپیتی [وو] هەیە: شت + و + مەک ← شت وومەک؛ کۆڵ + و + بار ← کوڵووبار؛ وت + و + وێژ ← وتووێژ.

١٠. /و/ لە بەستێنی سینتەکس

لە بەستێنی دەق و ئاخاڤتن و ئاوازی سینتەکسی، هەڵکەوتنی سرتێس و کۆنسۆنەنتی کۆتا بڕگە دەتوانێت هێزی خلی /و/ بگۆڕێت. لە فرێزی «من و تۆ» و «تۆ و من» دۆخی /و/ بە پێی شوێن و ئاواز و کۆنسۆنەنتەکانی دەوروبەر جوداواز دەبێت.

لە «تۆق و شانە» و «شانە و تۆ»دا، دۆخی کۆنسۆنەنت و ڤاوڵی کۆتا بڕگە هێزی هەڵگەراوەیی و خلی /و/ دەگۆڕێت و دەرکەوتنی ئەلۆفۆنی [وە] دەکرێت.

١١. دۆخەکانی بازنەکانی زوانی کوردیک

کتێب لە نموونەکانی «بوەتە ← بۆەتە = بۆتە»، «ئەمشەو ← ئەمشەۆ = ئەمشۆ»، «زیندوە ← زیندۆە = زیندۆ»، «هاتو ← هاتۆ»، «کردوە ← کردۆە = کردۆ»، «خواردو ← خواردۆ» و «چووەتە ← چۆەتە = چۆتە» ڕەوتی تێ‌چوونی ڤاوڵی [ە] و گۆڕانی فۆڕم لە بازنە باکور، باشور و هەورامی نیشان دەدات.

لە هەمان نموونەکان‌دا فۆڕمەکانی بازنەی باکور، باشور و هەورامی جوداواز دەردەکەون؛ وەک هاتی، هاتیە؛ ئامێنۆ، ئامێنەوە؛ خوارین، خوارینە؛ خواردۊد؛ واردێنەشۆ؛ چێە، چیە.

پوختەی وانە

لاپەڕەکانی ٥٣٠–٥٣٦ ڤاوڵی بەندبو، سرتێس، ڤاوڵی کێشاوە و بێ‌هێز، /شوا/، دەوری خلی /و/، ئاوێتەسازی مۆرفۆلۆجی، بەستێنی سینتەکسی و گۆڕانە فۆنێتیکیەکانی بازنەکانی زوانی کوردیک دەخەنەڕوو.
