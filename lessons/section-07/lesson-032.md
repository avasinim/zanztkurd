# وانەی ٣٢ — لێکچوونی بڕگە و گۆڕانی قاڵبی بڕگە

## ئامانجی وانە
لە کۆتایی ئەم وانەیەدا فێرخواز دەتوانێت جیاوازی نێوان بڕگەی سوک، بڕگەی گران و بڕگەی هەرە گران تێبگات و گۆڕانی قاڵبی بڕگە لە نموونە فۆنۆلۆجییەکاندا بناسێتەوە.

## ناوەڕۆک
کتێب لە ئەم بەشەدا لێکچوونی بڕگە و گۆڕانی قاڵبی بڕگە دەخاتەڕوو. لە نموونەکاندا بڕگەی `CV` دەتوانێت بۆ `CVC` بگۆڕێت، و بڕگەی `CVC` دەتوانێت بۆ `CVCC` یان `CCVC` فراوانتر بێت.

### نموونە
- `CV → CVC`
- `CVC → CV`
- `CVC → CVCC`
- `CVC → CCVC`

لە نموونەکانی کتێبدا «کپ → کیپ»، «گم → گوم» و «قم → قوم» بۆ گۆڕانی `CV` بۆ `CVC` هاتوون.

## بڕگەی دوو و چەند‌بڕگەیی
لە وشەی دووبڕگەییدا گۆڕانی قاڵبی یەک بڕگە دەتوانێت هاوسەنگی بڕگەکان بگۆڕێت؛ بۆ نموونە بڕگەی سوک دەتوانێت ببێتە بڕگەی گران، یان بڕگەی گران بۆ بڕگەی سوک بگۆڕێت.

## زاراوەکان
- بڕگە — Syllable
- قاڵبی بڕگە — Syllable Structure
- بڕگەی سوک — Light Syllable
- بڕگەی گران — Heavy Syllable
- بڕگەی هەرە گران — Superheavy Syllable
- لێکچوون — Transformation

## ڕاهێنان
1. بۆ هەر یەک لەم قاڵبانە نموونەیەک بنووسە: `CV`، `CVC`، `CVCC`، `CCVC`.
2. لە «کپ → کیپ» گۆڕانی قاڵبی بڕگە دیاری بکە.
3. جیاوازی بڕگەی سوک و گران بە نموونە ڕوون بکەوە.
4. یەک نموونە بۆ گۆڕانی `CVC → CVCC` بنووسە.

## کورتە
گۆڕانی قاڵبی بڕگە یەکێکە لە مبحثە گرنگەکانی ئەم بەشەی کتێب و پیشان دەدات کە پێکهاتەی فۆنۆلۆجیی وشە دەتوانێت بە گۆڕانی ڤاوڵ و کۆنسۆنەنت بگۆڕێت.
