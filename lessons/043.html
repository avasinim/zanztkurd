دەوری (ی) لە ئیزافە و ناوداڕێژین

/ی/ لە بازنەی مۆرفۆلۆجی

سەرچاوەی وانە: سابیر ژاکاو · فۆنێتیک و فۆنۆلۆجی کوردیک

١. دەوری /ی/ لە ئیزافەی پێکهێنان

لە بازنەی مۆرفۆلۆجی و دۆخ‌نوێنی‌دا، مۆرفۆفۆنێمی /ی/ دەوری ئیزافەی وەسفی دەگێڕێت و لە زوانی کوردیک‌دا لە کاتی سازکردنی ئاواڵناوی لێکدراو، دەورێکی چالاکی هەیە.

ئەم دیاردەیە لە ڕێزمانی عەرەبی و فارسیش ناسراوە و ناوی «ئیزافە»ی بۆ بەکار هاتوە.

  • دمی + فش → دمی‌فش
  • زوڵفی + خاو → زوڵفی‌خاو
  • سەری + پان → سەر‌ی‌پان
  • لیچی + شۆڕ → لیچی‌شۆڕ
  • ژنی + چاک → ژنی‌چاک
  • چاوی + کاڵ → چاوی‌کاڵ
  • دڵی + ناسک → دڵی‌ناسک

٢. /ی/ و داڕشتنی ناوی واتایی

کاتێک گیرەکی وشەداڕێژی واتایی و ئەبستاکت دەچێتە سەر ئاواڵناو، ناوی واتایی دادەڕێژێت.

  • کز → کزی
  • باریک → باریکی
  • پان → پانی
  • پیس → پیسی
  • خاوێن → خاوێنی
  • پاک → پاکی

٣. تێ‌چون و دەتوێنەوەی مۆرفۆفۆنێمی /ی/

لە ئاستی دۆخ‌نوێنی و پەیدابونی ئیزافەی پێکهێنان و سازکردنی ئاواڵناوی لێکدراو، مۆرفۆفۆنێمی /ی/ تێ‌دەچێت و دەتوێتەوە:

  • دمی + فش → دم‌فش
  • زوڵفی + خاو → زوڵفخاو
  • سەری + پان → سەرپان
  • لیچی + شۆڕ → لیچشۆڕ
  • ژنی + چاک → ژنچاک
  • چاوی + کاڵ → چاوکاڵ
  • دڵی + ناسک → دڵناسک

٤. /ی/ و بچوک‌کردنەوەی ناو

لە بازنەی مۆرفۆلۆجیکاڵ و سازکردنی ناوی داڕێژراو، /ی/ دەتوانێت ئەرکی مۆرفیمی داڕێژەر و بچوک‌کردنەوە بگێڕێت.

  • پشیلە → پشی
  • نازدار → نازی
  • دڵنیا → دڵی
  • گوڵزار → گوڵی
  • سۆزان → سۆزی

٥. /ی/ لە داڕشتنی ئاواڵکردار

لە بازنەی مۆرفۆلۆجیکاڵ، /ی/ لە داڕشتنی ئاواڵکرداردا دەرکەوێت:

  • ژێر → ژێری
  • خوار → خواری
  • بڵیند → بڵیندی
  • تەنیشت → تەنیشتی
  • بەرز → بەرزی
  • نەوی → نەویی

٦. گرێدان و نیسبیەت

لە زوانی کوردیک‌دا دۆخی /ی/ی گرێدان یا نیسبیەت، لە بازنەی سێمەنتیک و هەستی تاکی کورد و زوانی کوردیک‌دا، بە شێوەیەکی سروشتی و ژینگەیی هەڵسوکەوت لەگەڵ دەکرێت.

ئەم ئاستە لە بازنەی وشەناسی‌دا کاتێک پەیدا دەبێت کە کەسێک یا شتێک بە شوێن و جێگە، بە پیشە و کار، یا بە کەس و پەیوەندییەکی جێنێتیکی و خوێنی و هەندێک جار ناخوێنی و نامۆ دەبەستێتەوە و نیسبەتی پێ دەدات.

  • کورد + ی → کوردی
  • گوند + ی → گوندی
  • کێو + ی → کێوی
  • شار + ی → شاری
  • نیشتیمان + ی → نیشتیمانی
  • بازاڕ + ی → بازاڕی

٧. پەیدابونی [یی] دوای ڤاوڵ

کاتێک بڕگە و وشەکە بە ڤاوڵ کۆتایی هاتبێت، [یی] پەیدا دەبێت:

  • بانە + ی → بانەیی
  • قامیشلو + ی → قامیشلویی
  • زاخۆ + ی → زاخۆیی
  • هەڵەبجە + ی → هەڵەبجەیی
  • ئورفا + ی → ئورفایی
  • کۆیە + ی → کۆیەیی

٨. دۆخی جێناوی (ی)

لە دۆخی جێناوی دوەم‌کەسی تاک، /ی/ لەگەڵ ناو و ئاواڵناو دەرکەوێت:

  • سپی + ی → سپیی
  • نارنجی + ی → نارنجیی
  • هانی + ی → هانیی
  • سلێمانی + ی → سلێمانیی
  • شادی + ی → شادیی

٩. دۆخی جێناوی و کاری تێپەڕ و تێنەپەڕ

لە دۆخی کاری تێپەڕ و تێنەپەڕ لە دەمەکانی کات‌دا، دۆخی جێناوی سێیەم‌کەسی تاک و گرێدانی ناو و ئاواڵناو، دەرکەوتنی /ی/ و شێوەکانی لە نێو وشەکان‌دا دەردەکەوێت.

  • برسی + ی → برسیی بو
  • نەوی + ی → نەویی نیە

کورتەی وانە

لە لاپەڕەکانی ئەم وانەیەدا دەوری /ی/ لە ئیزافەی پێکهێنان، داڕشتنی ناوی واتایی، تێ‌چون و دەتوێنەوەی مۆرفۆفۆنێم، بچوک‌کردنەوەی ناو، داڕشتنی ئاواڵکردار، گرێدان و نیسبیەت، پەیدابونی [یی] دوای ڤاوڵ و دۆخی جێناوی باس کراوە.
