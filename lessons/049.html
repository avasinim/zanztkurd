دەوری مۆرفۆفۆنێمی /و/ لە زوانی کوردیک

دەوری /و/ لە فۆنۆلۆجی، مۆرفۆلۆجی، سینتەکس و فۆنێتیک و پەیوەندییەکەی بە [وو]

سەرچاوەی وانە: سابیر ژاکاو · فۆنێتیک و فۆنۆلۆجی کوردیک

١. /و/ لە فۆنۆلۆجی

لە ئاستی فۆنۆلۆجی، /و/ دەبێتە واچ و ڤاوڵێکی بەندبو. نمونەکانی کتێب: دور – دار – دیر – دێر – دەر – دۆر؛ پور – پار – پیر – پێر – پەر – پۆر.

٢. /و/ لە مۆرفۆلۆجی

/و/ وەک گیرەکی وشەداڕێژ دەردەکەوێت و دۆخی بچوک‌کردنەوە و نزدیکایەتی و ناوی گیانداران دەردەخات:

  • خان + و: خانو؛ ڕۆژ + و: ڕۆژو؛ داس + و: داسو
  • پوش + و: پوشو؛ پەت + و: پەتو؛ شار + و: شارو
  • قاژ + و: قاژو؛ ماز + و: مازو

لە دۆخی هێزی کۆتایی بڕگەش دەردەکەوێت: سەر + و: سەرو؛ ژێر + و: ژێرو؛ خوار + و: خوارو؛ هوار + و: هوارو؛ ژور + و: ژورو؛ پشت + و: پشتو.

٣. /و/ لە وشەی لێکدراو

مۆرفیمی /و/ لە شوێنی ناوەندی دو مۆرفیم بە یەکەوە دەبەستێت: دەنگ + و + باس: دەنگ و باس؛ نەرم + و + نۆڵ: نەرم و نۆڵ؛ مشت + و + مڕ: مشتومڕ؛ کت + و + پڕ: کت و پڕ.

لە وشەی لێکدراوی دژواتایی‌داش دەردەکەوێت: چاک + و + خراب: چاک و خراب؛ ڕەش + و + سپی: ڕەش و سپی؛ توند + و + شل: توند و شل.

٤. /و/ لە سینتەکس

لە ئاستی سینتەکس، /و/ دەوری بەستن دەگرێت و دو یا چەند فرێز و دەستەوشە بە یەکەوە دەبەستێت: زانست و زانین و فێرکردن...؛ مرۆڤ و بزن و پشیلە و گشت گیانداران...

لە دۆخی ڕەگ‌دا بۆ سازکردن و داڕشتنی چاوگیش دەردەکەوێت: چون، بون، گرون، درون، سون، جون، فەرمون.

٥. سازگەی /وو/ و /و/

/وو/ ڤاوڵێکی بەرزی کێشاوە و خڕە؛ لە بەرهەم‌هێنان‌دا لێوەکان زۆر خڕ دەبن و پشتەوەی زمان بەرز دەبێتەوە. /و/ ڤاوڵێکی نزم‌تر و کورتی خڕی بەرزی پشتەوەییە و ڕەوتی سازگەی نزیک بە /وو/ هەیە، بەڵام بەرزبونەوەی پشتەوەی زمان و خڕبونەوەی لێوەکان کەم‌ترە.

٦. [وو] و ڕێنوس

کتێب جەخت لە کەم‌کردنەوەی پیتە بێ‌کەڵکەکان دەکاتەوە. لە کۆتایی وشە، لە هەندێک دۆخ‌دا چ بە (و) و چ بە (وو) بنوسرێت جیاوازی فۆنێمی نیە. نمونەکان: بەڵکو، پەکو، تەکو، تاکو، ماکو، جوانو، خانو، مێژو.

لە سەرەتای وشە: ئو، ئورمیە، ئورامان، ئوتۆ، ئوتۆبوس، ئوستاد.

٧. ڕەوتی مێژوویی ڤاوڵ

نمونەکانی کتێب: چادر ← چاتور ← چاتوور؛ دز ← دوزد ← دووزد؛ چوار ← چەتور ← چەتوور؛ سپس ← سوپاس ← سووپاس؛ بن ← بونە ← بوونە؛ سپاس ← سوپاس ← سووپاس؛ دنیا ← دونیا ← دوونیا؛ قم ← قوم ← قووم؛ ترش ← تورش ← توورش؛ وشە ← ووشە.

٨. /و/ لە پڕۆسەی مۆرفۆلۆجی

دو + و + ان = دوان؛ کو + و + ان = کوان؛ خانو + و + ان = خانوان؛ مازو + و + ان = مازوان؛ زو + و + ە = زوە؛ بو + و + ە = بوە؛ کردو + و + ە = کردوە؛ بردو + و + ە = بردوە.

شێوەی زۆرکراوی کۆن: دوو + و + ان = دوووان؛ خانوو + و + ان = خانوووان؛ کردوو + و + ە = کردوووە. سترێس و هێزی دەنگی لە دو́ان، کو́ان، خانو́ان، مازو́ان، زو́ە، بو́ە، کردو́ە و بردو́ە باس دەکرێت.

پوختەی وانە

لاپەڕەکانی ٥٠١–٥١٩ دەوری /و/ لە فۆنۆلۆجی، مۆرفۆلۆجی، سینتەکس و فۆنێتیک، پەیوەندی /و/ و [وو]، ڕێنوس، ڕەوتی مێژوویی ڤاوڵ و پڕۆسەی مۆرفۆلۆجی دەخەنەڕو.
