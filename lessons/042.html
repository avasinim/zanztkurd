ئاوێتەبون، یەکبون و لێکدانی ڤاوڵەکان

/ی/ لە بازنەی فۆنۆلۆجی و مۆرفۆلۆجی

سەرچاوەی وانە: سابیر ژاکاو · فۆنێتیک و فۆنۆلۆجی کوردیک

١. تێ‌چونی ڤاوڵەکان لە یەکتر

ئەگەر دو ڤاوڵ بکەونە پاڵ یەکت و لە بازنەی فۆنۆلۆجیەوە ڤاوڵەکانی بەرز و نزم بن و یەکێک لە ڤاوڵەکان ڤاوڵی نزم بێت، بە شێوەیەکی ژینگەیی و سروشتی، میکانیزمی خۆزایی بەرهەم‌هێنان‌دا ڤاوڵە نزمەکە تێ‌دەچێت و دەتوێتەوە.

بۆ نمونە، ئەگەر دو ڤاوڵی /ە/ و /ی/ بکەونە پاڵ یەکت، بەپێی میکانیزمی فۆنێتیکی زوانی کوردیک، لە نێو یەکت دەتوێنەوە و دەبن بە یەک /ە/ و یەک /ی/.

٢. ڕێسای کەم‌کۆشین و سادەکردنەوە

ئەم بازنانە ڕێسای کەم‌کۆشین و سادەکردنەوەی جوان‌نوسی و ڕێسای زانستی زوان، لەوانیش زانستی ڕێنوس، و گرنگ‌تر ڕێسای مۆرفۆلۆجی و دۆخی تێ‌چون، بۆمان ڕێگەخۆشکەر دەکەن.

  • مامۆستا + ەکە = مامۆستاکە
  • سارا + ەکە = ساراکە
  • شانە + ەکە + ان = شانەکان
  • دارە + ەکە + ان = دارەکان
  • باغە + ەکە + ان = باغەکان
  • شادی + ین = شادین
  • هاری + ین = هارین
  • قوتابی + ین = قوتابین

٣. دۆخی تایبەتی مۆرفۆلۆجیکی

لە دۆخی تایبەتی مۆرفۆلۆجیکی خۆی‌دا، مۆرفیمێکی بەندی وشەداڕێژ و بازنەی دۆخ‌نوێنی و فۆنۆلۆجیەکەی چالاکە. دو یا چەند مۆرفیم لە بری ئەم مۆرفیمە دەردەکەون و جێگەی چالاکی لێکسیمی و مۆرفۆلۆجی ئەم مۆرفیمە پڕ دەکەنەوە، بێ ئەمەی کە ئەرکی واچی بگێڕێت و واتاگۆڕ بێت؛ دەبنە سینۆنیمی یەکتر.

ئەم مۆرفیمەی کە لەم بازنەیە جێی مۆرفۆفۆنێمی /ی/ دەگرێتەوە، مۆرفیمی بەندی (ێتی) و (انە) ـە.

  • ناشیرین + ی / ێتی / انە → ناشیرینی، ناشیرینێتی، ناشیرینانە
  • منداڵ + ی / ێتی / انە → منداڵی، منداڵێتی، منداڵانە
  • جوان + ی / ێتی / انە → جوانی، جوانێتی، جوانانە
  • پیر + ی / ێتی / انە → پیری، پیرێتی، پیرانە
  • درێژ + ی / ێتی / انە → درێژی، درێژێتی، درێژانە

٤. پەیدابونى ڤاوڵی ئازاد و کراوەی /ی/ لە کۆتایی بڕگە و وشە

لە دۆخی پەیدابونی ڤاوڵی ئازاد و کراوەی /ی/ لە کۆتایی بڕگە و وشە، نێوانجی /ی/ لە نێوان ناوی داڕێژراو و مۆرفیمەکان‌دا دەرکەوێت:

  • سپی + ی / ێتی / انە → سپیی، سپییێتی، سپییانە
  • نارنجی + ی / ێتی / انە → نارنجیی، نارنجییێتی، نارنجییانە
  • نەوی + ی / ێتی / انە → نەویی، نەوییێتی، نەوییانە
  • دزی + ی / ێتی / انە → دزیی، دزییێتی، دزییانە
  • برسی + ی / ێتی / انە → برسیی، برسییێتی، برسییانە

٥. ئاوێتەبون، یەکبون و لێکدانی ڤاوڵەکان

لە کاتی تێکەڵبون و پەیدابونی فۆنێمێکی جودا و جیاواز، نزیک لە یەک و لە میکانیزمی بەرهەم‌هێنانی فۆنێتیکیەوە، فۆنێکی تازە ساز دەبێت. ئەم دیاردەیە لە دەرکەوتنی ڤاوڵی /ی/ ئێگجار کەم و لە بازنەیەکی ژینگەیی ئەم زوانە دەردەکەوێت.

لە بازنەی زوانی ژینگەیی و ئەکسێنتی سلێمانی، لە تێکەڵبونی ڤاوڵی /ی/ و /ە/ پەیدابونی ڤاوڵی [ێ] دەردەکەوێت:

  • شادی + ی + ەکە → شادییەکە، شادیێکە [ی، ێ]
  • کوردی + ی + ەکە → کوردییەکە، کوردیێکە [ی، ێ]
  • یاری + ی + ەکە → یارییەکە، یاریێکە [ی، ێ]

٦. دەوری (ی) لە بازنەی مۆرفۆلۆجی

پیتی /ی/ لە بازنەی مۆرفۆلۆجیکی‌دا ئەرکی گیرەکی وشەداڕێژی واژەیی دەبینێت؛ کە بدرێتە ئاواڵناو بۆ داڕشتنی ناو، چالاکیەکەی دەردەکەوێت و فۆنێکی بڕگەیی ساز دەکات و بڕگەکە دەکاتە دو بڕگەیی.

  • باش → باشی — Başî
  • خراپ → خراپی — Xirapî
  • سوری → سوری — Surî
  • ناسک → ناسکی — Naskî
  • بەخت → بەختی — Bextî
  • مەست → مەستی — Mestî
  • غەم → غەمی — Xˈemî
  • شاد → شادی — adîş

٧. دەرکەوتنی [یی] لە کۆتایی وشە

ئەگەر بڕگە و وشەکە بە ڤاوڵ کۆتایی هاتبێت، دەرکەوتنی [یی] لە پاش ڤاوڵەکان‌دا لەگەڵ پیتی ڤاوڵی /ی، î/ جیاوازە. ئەگەر پیتی /ی/ دەربکەوێت، بەهۆی دەرنەکەوتنی دو ڤاوڵ بە دوای یەکت، دۆخی کۆنسۆنەنتی زیادبون یا پەیدابونی کۆنسۆنەنت دەردەکەوێت.

لەم دۆخەدا، ڕیشەی وشەکە بە ڤاوڵ کۆتایی دێت و سیستمی فۆنێتیکی زوانی کوردیک دو ڤاوڵ لە پاڵ یەکت پەیدا ناکات. /ی/ یەکەم کۆنسۆنەنت و /ی/ دوەم ڤاوڵە:

  • نامۆ + ی = نامۆیی — Namoyî
  • مامۆستا + ی = مامۆستایی — Mamostayî
  • بانە + ی = بانەیی — Baneyî
  • شارەزا + ی = شارەزایی — Şarezayî
  • تەنی + ی = تەنیایی — Tenyayî
  • زانا + ی = زانایی — Zanayî
  • سورمە + ی = سورمەیی — Surmeyî
  • قاوە + ی = قاوەیی — Qaweyî
  • پەمە + ی = پەمەیی — Pemeyî
  • خەنە + ی = خەنەیی — Xeneyî
  • سپی + ی = سپییی — Spîyî
  • نارنجی + ی = نارنجییی — Narincîyî

٨. کورتەی وانە

لاپەڕەکانی ئەم وانەیە دۆخی تێ‌چونی ڤاوڵەکان، ڕێسای کەم‌کۆشین و سادەکردنەوە، دۆخی مۆرفۆلۆجیکی مۆرفیمەکانی (ێتی) و (انە)، ئاوێتەبون و یەکبون و لێکدانی ڤاوڵەکان، دەوری پیتی /ی/ لە وشەداڕێژ و دەرکەوتنی [یی] لە کۆتایی وشە باس دەکات.
