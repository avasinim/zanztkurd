# وانەی ١٤ — زنجیرەی هێشوی کۆنسۆنەنتی

## پێشەکی

لە کتێبدا باسی **زنجیرەی هێشوی کۆنسۆنەنتی** دەکرێت؛ واتە دو یان چەند کۆنسۆنەنت لە زنجیرەی دەنگیدا بەبێ پەیدابونی ڤاوڵ لە نێوانیان.

## زنجیرەی هێشوی کۆنسۆنەنتی

زنجیرەکە دەتوانێت لە سەرەتای بڕگە، لە کۆتایی بڕگە، یان لە دو لای بڕگەدا دەربکەوێت.

زاراوەکانی سەرەکی:

- **Initial Consonant Cluster** — هێشوی کۆنسۆنەنتی سەرەتایی
- **Onset** — هێشوی پێشەوە
- **Twin Consonant Cluster** — هێشوی کۆنسۆنەنتی دولابەندی
- **Final Consonant Cluster** — هێشوی کۆنسۆنەنتی کۆتایی
- **Coda** — هێشوی پاشەوە

## نموونە

لە وشەکانی:

- پشت
- ماست
- دەست
- دەشت
- ڕاست

هێشوی کۆنسۆنەنتی کۆتایی یان پاشەوە دەبینرێت.

لە نموونەکانی:

- ست
- شت
- پف
- پڕ
- زڕ
- دز
- مڕ

هێشوی کۆنسۆنەنتی وەک وەچەپێکهاتەی پاشکۆیی دەردەکەوێت.

## سازگەی دویەیی

لە هەندێک هێشوی کۆنسۆنەنتیدا یەک فۆن لە سازگەی سەرەکی و فۆنێکی تر لە سازگەی ناسەرەکی بەرهەم دێت.

نموونە:

- **خو** ← /xʷ/
- **گو** ← /gʷ/
- **کو** ← /kʷ/

وشەی نموونە:

- خوەم
- خوشک
- خوا
- خوێ
- خوێن
- گوێ
- گوارە
- گوێز
- کوێ
- کوێستان

## تێبینی فۆنۆلۆجی

لە هەندێک زنجیرەی کۆنسۆنەنتیدا هیچ ڤاوڵێک لە نێوان کۆنسۆنەنتەکاندا دەرناکەوێت. ئەمە جیاوازە لەو دۆخەی کە شوا بە شێوەی نیمچە ڤاوڵ دەرکەوێت.

## ڕاهێنان

1. زنجیرەی هێشوی کۆنسۆنەنتی چییە؟
2. پێنج وشە بنوسە کە زنجیرەی هێشوی کۆنسۆنەنتی تێدا بێت.
3. جیاوازی هێشوی سەرەتایی و هێشوی کۆتایی ڕوون بکەوە.
4. لە وشەکانی خو، گو و کو، سازگەی دویەیی چۆن دەردەکەوێت؟
5. وشەکانی پشت، ماست، دەست، دەشت و ڕاست بە پێی هێشوی کۆنسۆنەنت شی بکەوە.
