# وانەی ٦

## پیتی (ر، ڕ)

ئەم وانەیە لە کتێبەکەدا بە ژمارەی **وانەی ٦٥** هاتووە و باسی دو پیتی نەلکاوی **ر** و **ڕ** دەکات. لە دەقی سەرچاوەدا ئەم دو پیتە بە پیتی دەیەم و یازدەیەمی نەبزوێنان/کۆنسۆنەنتەکان ناسێنراون. fileciteturn83file0L24-L39

### ١. پیتی (ر)

لە وانەکەدا **ر** بە **نزم و سوک/ناسک** ناسێنراوە و زاراوەی **Lenis — نزم** بۆی هاتووە. fileciteturn83file0L30-L35

لە دەقی وانەکەدا جەخت لەوە دەکرێتەوە کە ر لە هەندێک دۆخی فۆنۆلۆجی و ڕێنووسیدا هەڵسوکەوتی تایبەتی هەیە و نابێت بە هەر شێوەیەک بە ڕ لە یەک بگیرێت. fileciteturn83file0L59-L67

### ٢. پیتی (ڕ)

**ڕ** لە وانەکەدا بە **بەرز و قورس** ناسێنراوە و زاراوەی **Fortis — بەرز** بۆی بەکار هاتووە. هەروەها بە پیتێکی نەلکاو و دەنگێکی فۆنێکی پوکی ناسێنراوە. fileciteturn83file0L37-L39

لە نووسینی ڕێنوسی ڕاست‌چین، ڕ بە دو نگار و دو شێوەی ئەلۆگرافی **ڕ، ــڕ** دەردەکەوێت. fileciteturn83file0L67-L74

### ٣. ر و ڕ دەتوانن واتا جیا بکەنەوە

یەکێک لە بەشە گرنگەکانی وانەکە ئەوەیە کە ر و ڕ تەنیا دو شێوەی نووسینی یەک دەنگ نین؛ لە نموونەکانی کتێبدا جیاوازییان دەتوانێت ببێتە هۆی جیاوازیی واتا. fileciteturn83file0L43-L58

نموونەکان:

| ر | ڕ |
|---|---|
| کەر | کەڕ |
| برین | بڕین |
| وەرین | وەڕین |
| سور | سوڕ |
| قور | قوڕ |
| مەر | مەڕ |
| دەر | دەڕ |
| گۆر | گۆڕ |
| باران | باڕان |
| شۆر | شۆڕ |
| لار | لاڕ |
| ئاور | ئاوڕ |
| برۆ | بڕۆ |
| پەری | پەڕی |

ئەم جوتە وشانە لە دەقی وانەی سەرچاوەکەدا هاتوون. fileciteturn83file0L43-L58

### ٤. شوێنی دەرکەوتنی ڕ

لە وانەکەدا نموونەی دەرکەوتنی **ڕ** لە سەرەتای وشە، ناوەڕاست و کۆتایی هاتووە؛ وەک:

- سەرەتای وشە: **ڕێناس، ڕامان، ڕۆژاوا، ڕەنگ، ڕەش، ڕێزوان**
- ناوەڕاست: **توڕە، دڕین، وەڕین، تێپەڕین، دڕندە**
- کۆتایی: **کەڕ، مەڕ، لاڕ، خاڕ، شەڕ، کوڕ، گۆڕ**

ئەم نموونانە لە کتێبەکەوە هاتوون. fileciteturn83file0L70-L84

### ٥. شوێنی دەرکەوتنی ر

وانەکە نموونەیەکی فراوان بۆ **ر** لە ناوەڕاست و کۆتایی وشە دەدات؛ وەک:

**کوردستان، جاران، باران، سارا، کارا، وریا، دەریا، هەورامان، مەریوان، ئاران، بیرەوەری، ناردن، یادگاری**. fileciteturn83file0L89-L101

### ٦. بۆچی جیاوازیی ر و ڕ گرنگە؟

لە ڕوانگەی وانەکە، هەر یەک لە ئەم دو کۆدە فۆنێمی و واژیی تایبەتی خۆی هەیە. بۆیە گۆڕینی یەکێکیان بە یەکەکەی دیکە دەتوانێت کۆدی فۆنێمی و واتایی وشە بگۆڕێت. fileciteturn86file0L11-L20

ئەمە بنەمایەکی گرنگە بۆ فێربوونی ڕێنووس: فێرخواز دەبێت **نیشانەی نووسین، فۆن و واتا** بە یەکەوە ببینێت، نەک تەنیا شێوەی پیتەکە.

### ٧. سازگەی بەرهەمهێنانی ر و ڕ

لە بەشی فۆنێتیکی وانەکەدا، **ر** وەک فۆنێکی ژێدار و لەرەری لێدانی سادەی بە مەڵاشوکراوی پوکی باس کراوە. دەقی کتێب باس لە جوڵەی نوکی زمان و نزیکبوونەوەی لایەکانی زمان لە ددانەکانی سەرەوە دەکات. fileciteturn83file0L108-L112

**ڕ** بە فۆنێکی ژێدار و لەرەری چەند لێدانی و مەڵاشویی پوکی باس کراوە؛ لە کاتی بەرهەمهێناندا نوکی زمان چەند جار لە یەک بە دوای یەک دەجوڵێت و دەدات. fileciteturn83file0L116-L119

## تمرینی وانە

### تمرینی ١
پێنج وشە بنووسە کە پیتی **ر**ی تێدا بێت.

### تمرینی ٢
پێنج وشە بنووسە کە پیتی **ڕ**ی تێدا بێت.

### تمرینی ٣
جیاوازی پیتی **ڕ** و **ر** چییە؟

### تمرینی ٤
بە نموونەیەک ڕوون بکەرەوە کە چۆن جیاوازیی ر و ڕ دەتوانێت واتای وشە بگۆڕێت.

پرسیارەکانی سەرەکیی وانەکە لە کتێبدا بە هەمان شێوە هاتوون: نووسینی وشە بۆ ر و ڕ، ڕوونکردنەوەی جیاوازییان و پرسیار لە دەرکەوتنی ڕ لە سەرەتای وشە. fileciteturn85file0L28-L39

## تاقیکردنەوەی کۆتایی

**١.** ر لە وانەکەدا بە چی ناسێنراوە؟

- نزم و سوک/ناسک
- بەرز و قورس
- ڤاوڵ
- پیتی لکاو

**٢.** ڕ لە وانەکەدا بە چی ناسێنراوە؟

- نزم
- بەرز و قورس
- ڤاوڵی نزم
- گرافیمی بێ دەنگ

**٣.** کام جوتەیە نموونەی جیاوازیی واتایی بە هۆی ر و ڕە؟

- کەر / کەڕ
- دایک / دادە
- بە / پە
- خاڵ / خال

**٤.** Sound Distribution بە کوردی چییە؟

- دابەش‌بونی دەنگ
- بەرزبوونی دەنگ
- ڕێنووس
- بڕگە
