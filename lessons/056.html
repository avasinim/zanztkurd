گۆڕانی مێژوویی /شوا/ بۆ ڤاوڵەکان

فۆنێتیکی مێژوویی، ئێتیمۆلۆجی و گۆڕانەکانی /شوا/ لە زوانی کوردیک

سەرچاوەی وانە: سابیر ژاکاو · فۆنێتیک و فۆنۆلۆجی کوردیک

١. ڕەوتی گۆڕان

لە فۆنێتیکی مێژوویی و ئێتیمۆلۆجی‌دا، /شوا/ دەتوانێت بۆ ڤاوڵە بەرزتر و درێژتر بەرز بکرێتەوە. کتێب ئەم ڕەوتە بە شێوەی زنجیرەی فۆنێتیکی نیشان دەدات.

٢. گۆڕانە سەرەکیەکان

[a ← ə]، [ê ← ə]، [→ ua ← u ← ə] و [ → ya ← î ← ə] لە نمونەکانی کوردستان، قەمار، بریتان، دەرەنگ، زوان، شوان، خواست، دوان، ژوان، گیان، نیان و ڤیان‌دا نیشان دراون.

٣. نمونە مێژووییەکان

چادر ← چاتور، زوان ← زووان، شمار ← شومار، دز ← دوزد، چوار ← چەتور، سپس ← سوپاس، بن ← بونە و نمونەکانی دیکە، ڕەوتی گۆڕانی مێژوویی /شوا/ نیشان دەدەن.

٤. گۆڕان بۆ ڤاوڵەکانی دیکە

کتێب هەروەها [ɛ ← ə]، [ē ← ə]، [o ← ə] و [eː ← ə] بە نمونەی زوانی کوردیک و نمونەی وشە و تێرمە وەرگیراوەکان شی‌دەکاتەوە.
